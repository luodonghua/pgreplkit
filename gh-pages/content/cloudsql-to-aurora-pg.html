Overview

You are migrating from Google Cloud SQL for PostgreSQL to Amazon Aurora PostgreSQL — a cross-cloud move. Use logical replication: Replication Copy or a pg_dump seed. Physical seeds are provider-specific and do not apply here.

Enable logical decoding on Cloud SQL (the source) Set the cloudsql.logical_decoding = on flag and restart, then grant REPLICATION to the migration user.
bash — gcloud 
gcloud sql instances patch MY_CLOUDSQL_INSTANCE \
  --database-flags=cloudsql.logical_decoding=on
#   SHOW wal_level;   -- expect: logical
Cross-cloud networking Cloud SQL is the publisher; the Aurora writer (subscriber) connects outbound to Cloud SQL on 5432. Use a public IP + Cloud SQL authorized networks (with SSL), or a VPN / Cloud Interconnect. Verify reachability from the Aurora VPC first:
bash — from the Aurora VPC 
psql "host=CLOUDSQL_IP port=5432 user=repluser dbname=appdb sslmode=require" -c "select 1"
