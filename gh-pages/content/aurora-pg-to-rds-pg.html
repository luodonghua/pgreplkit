Overview

You are moving from Amazon Aurora PostgreSQL to Amazon RDS for PostgreSQL — for example, to leave Aurora for standard RDS. These are different engines, so physical seeds (Aurora clone, RDS snapshot) do not cross between them. Use logical replication: Replication Copy or a pg_dump seed.

Enable logical WAL on the source (Aurora) Set rds.logical_replication = 1 in the source's DB cluster parameter group (static → reboot). Confirm with SHOW rds.logical_replication;.
Networking The RDS instance (subscriber) connects to the Aurora writer (publisher) on 5432. Use the Aurora writer's private address and allow the VPC CIDR on the Aurora security group.
