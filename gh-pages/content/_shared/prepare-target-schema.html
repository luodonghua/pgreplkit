Prepare the target schema

The Replication Copy method copies data, not DDL: the tables (with their columns, types, and constraints) must already exist on the target before you subscribe. Create them from the source's schema:

bash — copy schema only (no data) 
pg_dump --schema-only \
  "host=SOURCE_HOST port=5432 user=repluser dbname=appdb" \
| psql "host=TARGET_HOST port=5432 user=repluser dbname=appdb"
Roles / globals first pg_dump --schema-only does not include roles. If your objects are owned by specific roles, create those roles on the target first (e.g. from pg_dumpall --roles-only, dropping anything managed-platform-specific). On RDS/Aurora targets, pgreplkit's globals step can recreate roles for you.
