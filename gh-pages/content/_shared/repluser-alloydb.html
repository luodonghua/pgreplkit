Create the replication user (on the source)

The subscriber connects to the source as this role, so create it on the source (publisher). On AlloyDB, use the alloydbsuperuser role to create a login role with the REPLICATION capability.

psql — on SOURCE (AlloyDB), as alloydbsuperuser 
CREATE ROLE repluser WITH LOGIN REPLICATION PASSWORD 'strong-secret';

GRANT USAGE ON SCHEMA app TO repluser;
GRANT SELECT ON ALL TABLES IN SCHEMA app TO repluser;
ALTER DEFAULT PRIVILEGES IN SCHEMA app GRANT SELECT ON TABLES TO repluser;  -- future tables too
Private-IP only AlloyDB has no public endpoint. The AWS subscriber must reach it over a VPN or Cloud Interconnect between the GCP and AWS VPCs (see the networking note above). There is no pg_hba.conf to edit.
On the subscriber (target, RDS/Aurora) The subscribing role needs rds_superuser (PG < 16) or rds_replication + pg_create_subscription (PG 16+) — see the target row of the prerequisites table above.
