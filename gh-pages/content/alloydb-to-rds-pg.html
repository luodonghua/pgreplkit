Overview

You are migrating from Google AlloyDB for PostgreSQL to Amazon RDS for PostgreSQL — a cross-cloud move. AlloyDB is PostgreSQL-compatible and can act as a logical-replication publisher, so use Replication Copy or a pg_dump seed. Provider-specific physical seeds do not apply.

Enable logical decoding on AlloyDB (the source) Set the alloydb.logical_decoding = on database flag on the AlloyDB instance and restart it. Use the alloydbsuperuser role (or a role granted REPLICATION) for the migration.
SQL / verify 
-- after setting the flag and restarting:
SHOW wal_level;   -- expect: logical
AlloyDB is private-IP only AlloyDB does not offer a public endpoint, so the RDS subscriber must reach it over a VPN or Cloud Interconnect between the AWS VPC and the GCP VPC. There is no public-IP shortcut. Establish and test that private path before you start:
bash — from a host in the RDS VPC (over the VPN) 
psql "host=ALLOYDB_PRIVATE_IP port=5432 user=repluser dbname=appdb sslmode=require" -c "select 1"
