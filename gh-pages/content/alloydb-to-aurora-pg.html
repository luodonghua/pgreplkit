Overview

You are migrating from Google AlloyDB for PostgreSQL to Amazon Aurora PostgreSQL — a cross-cloud move. Use logical replication: Replication Copy or a pg_dump seed.

Enable logical decoding on AlloyDB (the source) Set the alloydb.logical_decoding = on flag and restart, then use alloydbsuperuser (or a role granted REPLICATION).
SQL / verify 
SHOW wal_level;   -- expect: logical
AlloyDB is private-IP only The Aurora writer (subscriber) must reach AlloyDB over a VPN or Cloud Interconnect between the AWS and GCP VPCs — there is no public endpoint. Establish and test that path first:
bash — from the Aurora VPC (over the VPN) 
psql "host=ALLOYDB_PRIVATE_IP port=5432 user=repluser dbname=appdb sslmode=require" -c "select 1"
