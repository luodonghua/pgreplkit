Overview

Both sides are Amazon Aurora PostgreSQL. This unlocks the fastest seed of all: an Aurora Fast Clone is copy-on-write, so the target cluster is ready in minutes no matter how large the data, and logical replication then streams the delta. For smaller data, Replication Copy is simpler; pg_dump is the middle option.

Enable logical WAL on the source Set rds.logical_replication = 1 in the source's DB cluster parameter group (static → reboot). Confirm with SHOW rds.logical_replication;.
Networking The clone's writer (subscriber) connects to the source writer (publisher) on 5432. Use the source writer's private address and allow the VPC CIDR on the source security group; Aurora public endpoints can hairpin to public IPs inside a VPC.
Clone seed = same major version A clone is always the source's major version. For a cross-version move, use Replication Copy or pg_dump. To upgrade and use the clone, capture the seed LSN before upgrading the clone (see the note in the clone setup) — the same pattern AWS Blue/Green Deployments use.
