Overview

You are moving from Amazon RDS for PostgreSQL to Amazon Aurora PostgreSQL. Although both are AWS-managed, they are different engines, so the physical seeds (RDS snapshot restore, Aurora fast clone) do not apply across them — a snapshot can't restore across the RDS/Aurora boundary. Use logical replication: Replication Copy or a pg_dump seed.

Enable logical WAL on the source (RDS) Set rds.logical_replication = 1 in the source RDS DB parameter group (static → reboot). Confirm with SHOW rds.logical_replication;.
Networking The Aurora writer (subscriber) connects to the RDS instance (publisher) on 5432. Same VPC, private address, and allow the VPC CIDR on the RDS security group.
Good news: version-independent Because this path is logical, it streams across major versions — you can land on a newer Aurora major version than the RDS source in the same migration.
