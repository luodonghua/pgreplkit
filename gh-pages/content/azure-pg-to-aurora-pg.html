Overview

You are migrating from Azure Database for PostgreSQL – Flexible Server to Amazon Aurora PostgreSQL — a cross-cloud move. Use logical replication: Replication Copy or a pg_dump seed.

This guide covers Flexible Server only Not the retired Single Server, nor Cosmos DB for PostgreSQL (Citus). On Single Server, move to Flexible Server (or dump/restore) first, then replicate.
Enable logical replication on Azure (the source) Set wal_level = logical (and adequate max_replication_slots / max_wal_senders), then restart. Use azure_pg_admin and grant REPLICATION to the migration user.
bash — az CLI 
az postgres flexible-server parameter set \
  --resource-group MY_RG --server-name MY_AZ_SERVER \
  --name wal_level --value logical
az postgres flexible-server restart \
  --resource-group MY_RG --name MY_AZ_SERVER
#   SHOW wal_level;   -- expect: logical
Cross-cloud networking Azure Flexible Server is the publisher; the Aurora writer (subscriber) connects outbound to it on 5432. Public access + Azure firewall rules (SSL), or a site-to-site VPN. Verify from the Aurora VPC first:
bash — from the Aurora VPC 
psql "host=MY_AZ_SERVER.postgres.database.azure.com port=5432 user=repluser dbname=appdb sslmode=require" -c "select 1"
