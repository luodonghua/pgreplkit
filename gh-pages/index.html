About This Guide

This is a manual setup guide. Every scenario gives you the exact SQL and shell commands to run by hand, so you understand and control each step. It does not require any tool to be installed against your databases.

It is a companion to pgreplkit, which automates these same workflows (slot planning, exactly-once physical seeds, validation gates, reverse replication) when you'd rather not run the steps yourself.

New to logical replication? Logical replication streams row-level changes from a publisher to a subscriber using a publication (what to send) and a subscription (what to receive). Unlike physical/streaming replication, it works across different major versions and different platforms — which is why it's the backbone of near-zero-downtime migrations and upgrades.
